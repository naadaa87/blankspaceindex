SVDI 1.1
Expert-designed
목적
이 공간은 왜 비어 있고, 무엇부터 바꿔야 하는가 — 비어 있는 이유를 가격·물리·설비·법규·상권·계약·노출·관리의 여덟 갈래로 나눠 확인하고, 무엇부터 바꿀지 순서를 잡아 드립니다.
적용 범위
임대 목적의 상업용 공간(점포·사무 구획). 문의·방문 흐름 데이터가 없으면 응답 기반 한계가 명시됩니다.
사용 데이터
건축HUB 건축물대장 · R-ONE 임대동향 통계 · 지방행정 인허가 자료 · 소상공인 상권정보 · 도로명주소 API + 사용자 응답. 수집 기준시점은 결과에 병기됩니다.
한계
  • Standard는 응답 기반 진단입니다. 주도 원인의 확정과 해소 기간 전망은 제시하지 않습니다.
  • 설비·정면성처럼 현장에서만 확정되는 축은 확인 필요로 남기고, 추정으로 채우지 않습니다.
  • 적정임대료 진단과 영업 가능성 확인의 결과가 있으면 가격·법규 축의 증거로 자동 연결됩니다.
검증 상태
전문가 설계(Expert-designed) 단계 — 10년의 실행 경험과 공인 방법론으로 설계되었으며, 실제 사례 보정을 앞둔 단계입니다.. 진행 상황은 검증 현황에 반영됩니다.
버전 이력
  • 1.1문의·방문 흐름을 최우선 증거로 확정, Standard의 원인 후보 2개 상한과 확인 순서 산출 정식화
  • 1.0여덟 개 원인 축과 어셈블리 입력 구조의 최초 설계

적정임대료 진단

SRVI 2.1
Expert-designed
목적
지금 조건이 시장과 맞는가. 재계약 때 얼마를 불러야 하는가 — 보증금과 렌트프리까지 반영한 실질 임대 조건을 시장 범위 위에 올려놓고, 지금 조건이 어디쯤인지 확인합니다.
적용 범위
상업용 임대 공간의 조건 진단. 감정평가액·확정가·보증가 용도로는 사용할 수 없습니다.
사용 데이터
건축HUB 건축물대장 · 실거래가 공개 자료 · R-ONE 임대동향 통계 · 도로명주소 API + 사용자 응답. 수집 기준시점은 결과에 병기됩니다.
한계
  • 결과는 감정평가액이 아니며, 확정가·보증가로 쓸 수 없습니다.
  • 신뢰도 미충족 시 범위를 제시하지 않습니다. 좁은 표본 위에서 숫자를 단정하지 않기 위한 규칙입니다.
  • 실거래·통계에는 신고 시차가 있어, 결과에는 수집 기준시점이 함께 표기됩니다.

  • 2.0유효임대료(ENR) 기준과 3트랙 동적 가중의 최초 설계

  • 조례팩이 아직 없는 지역은 해당 관문을 확인 필요로 발행합니다. 팩 부재가 그대로 표기됩니다.
