판정 경계값과 산출 규칙의 조정은 근거와 함께 버전으로 기록됩니다. 이미 발행된 결과지는 발행 당시의 버전을 따르며, 개정으로 소급 변경되지 않습니다.

공실 원인 진단 SVDI

  1. 1.1

    문의·방문 흐름을 최우선 증거로 확정, Standard의 원인 후보 2개 상한과 확인 순서 산출 정식화

    현행
  2. 1.0

    여덟 개 원인 축과 어셈블리 입력 구조의 최초 설계

적정임대료 진단 SRVI

  1. 2.1

    신뢰도 C 발행 규칙(60 이상 발행)과 등가 조합 산출 확정, 가격·점수·신뢰도 분리 표기

    현행
  2. 2.0

    유효임대료(ENR) 기준과 3트랙 동적 가중의 최초 설계

영업 가능성 확인 SCPI

  1. 1.1

    조건 분기 응답의 확실도 하향과 "모름 → 확인 필요 유지" 규칙 보완, 판정선 인접 구간 확대

    현행
  2. 1.0

    8관문 체인과 4상태·전파 규칙, 위음성 0 원칙의 최초 설계

공간수익화 적합성 평가 SMFI

  1. 2.1

    점수와 신뢰도의 분리로 이중 감점 해소, 판정 4등급과 경제성 검증 단계 확정

    현행
  2. 2.0

    5단계 파이프라인과 하드게이트·57지표 체계의 최초 설계
